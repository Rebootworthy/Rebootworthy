# Rebootworthy

### Old tech. New purpose.

I'm building, breaking, rebuilding, and documenting a home lab focused on self-hosting, networking, automation, local AI, and finding new uses for older hardware.

## 🖥️ The Homelab

- **HP Z8 G4** — Proxmox virtualization host
- **Synology DS418play** — NAS, backups, and storage
- **Raspberry Pi 5** — Pi-hole and network services
- **Cisco Catalyst 2960-CX** — Homelab switching
- **Ubuntu Server** — Docker and self-hosted applications

## 🚀 Current Projects

- Self-hosted photo management with **Immich**
- Network-wide DNS filtering with **Pi-hole**
- Monitoring with **Uptime Kuma**
- Homelab dashboard with **Homarr**
- Secure remote access with **Tailscale**
- Custom **HYROX touchscreen dashboard**
- Building toward a **local AI assistant**
- Expanding network segmentation and VLANs
- Repurposing old hardware into useful projects
